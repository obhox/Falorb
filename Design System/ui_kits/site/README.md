# Marketing site UI kit

The Falorb marketing home at 1440 wide. Open `index.html`.

Sections, in order: sticky glass nav → hero (badge, 62px display headline, dual CTA, mono trust row) →
product shot (a real composition of `StatTile`, hatched bars, `GlassPanel` hover card and `MetricBar` rows
inside a floating panel, with the system's one sanctioned glacier glow behind it) → feature grid (6 tiles) →
install block (two mono command blocks, working copy button) → pricing (3 plans, middle one featured with a
glacier hairline) → footer.

| File | Role |
| --- | --- |
| `SiteHero.jsx` | `SiteNav`, `Hero`, `ProductShot` |
| `SiteSections.jsx` | `FeatureGrid`, `InstallBlock`, `Pricing`, `SiteFooter` |

Copy follows the content fundamentals in the root `readme.md`: sentence case, figures instead of adjectives,
no emoji, no exclamation marks.
