One-line: square icon-only control for toolbars, table rows, and panel headers.

```jsx
<IconButton label="Refresh" icon={<Icon name="refresh-cw" />} />
<IconButton label="Filters" icon={<Icon name="sliders-horizontal" />} active variant="solid" />
```

Default variant is ghost (invisible until hover). `active` holds the pressed tint for toggles.
